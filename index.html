TCG Tool Web

GUI interface "all-in-one" for managing a couple of Time Code Generators that work on the serial+SSH+UDP protocols. Gives the user the option to configure a device without jumping between tools.

Problem

TCG devices use serial line commands like GRT 1,2,g... that are not human-readable. To configure a device, the user needs to use 3 protocols.

How solved

Friendly UI that translates a data line into human-readable data. All 3 protocols in the same app. Configuration for decoding is changeable.

Where used now

One of the big projects that use a TCG with serial interface(10+ devices). Exists option to be the official program for using TCG devices.

Manager of File Bus Pipeline

1 Part of File Bus Infrastructure. App that controls and monitors Workers (2 Part). Made commands to the Workers and show their status and responses.

Problem

How to run a pipelines and commands if connection between a Master and Slaves is only with a Shared Folder.

How solved

Manager create a file .json in the shared folder with data to start a pipeline,Worker check this file, run a pipeline and responce output of command in the another .json file.

Where used now

In the 2 Stand-alone networks that connected to company network only with one shared folder.

Worker of File Bus Pipeline

2 Part of File Bus Infrastructure. App that executes commands from the Manager and sends back the output of the commands.

Problem

How to run a pipelines and commands if connection between a Master and Slaves is only with a Shared Folder.

How solved

Worker check a folder for the new .json files,execute a commands form him with his config file and send a output back with .json..

Where used now

In the 2 Stand-alone networks that connected to company network only with one shared folder.

SDR Network Planning Tool

GUI tool that allows the user to create a configuration of a Software Defined Radio Network and then generates an XML file with the network configuration.This file used after on the devices to know how use a network.

How solved

Use an Infrastructure of Devices to change all config with one XML file

Where used now

Used like a code-base for the real tool that is now in using on the side of clients.
